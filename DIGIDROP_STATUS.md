# DigiDrop: состояние проекта

## Основа
- Отдельный Android-проект DigiDrop на базе предоставленного QRHelper source archive.
- Видимое имя приложения: DigiDrop.
- Основная архитектура пока локальная: backend/Firebase не добавлялись.
- Камера: CameraX + ML Kit Barcode Scanning.

## Рабочие этикетки
- На фото коробок читается длинный линейный GS1-подобный идентификатор с AI `01`, `11`, `21`.
- В проекте ML Kit сканирует все поддерживаемые форматы; точная обработка GS1 AI и сканирование на устройстве ещё не подтверждены.
- На бумажном документе есть линейный штрихкод с подписью `RU0141582293` и отдельный 2D-код. Формат 2D-кода по фото достоверно не определён.

## Текущее состояние функций
- [x] Камерный сканер CameraX + ML Kit присутствует в исходнике.
- [x] Импорт CSV/TSV с кавычками, разделителями и координатами присутствует в подготовленной рабочей копии.
- [x] Тестовая кнопка фиктивного штрихкода удалена из подготовленной копии.
- [x] Фейковый демо-маршрут удалён из стартового состояния подготовленной копии.
- [ ] XLSX не реализован.
- [ ] PDF/скан-фото накладных как импорт маршрута не реализованы.
- [ ] Группировка рейс → точка → документы → товары → упаковки требует доработки.
- [ ] Сверка фактических упаковок, пропусков, дублей и неизвестных кодов не подтверждена.
- [ ] Геокодирование адресов и дорожная маршрутизация не реализованы.
- [ ] Проверка на реальных этикетках и Android-устройстве не проведена.

## CI
Workflow `.github/workflows/android.yml` собирает `assembleDebug` на Ubuntu и публикует APK как GitHub Actions artifact. Первый запуск проверит SDK `android-37` и совместимость зависимостей.

## Честный статус
Не считать приложение готовым к рабочему рейсу, пока не проверены импорт реального файла накладной, сканирование всех типов кодов и сверка количества мест на Android-устройстве.
